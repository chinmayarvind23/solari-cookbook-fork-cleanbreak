# CleanBreak Implementation Status

- Current milestone: Milestone 6 — CleanBreak Receipt.
- Receipt boundary: only a job with a durable `VERIFIED` job state and stored `VERIFIED` verification result can create a receipt. `VERIFYING`, `NOT_VERIFIED`, `INCONCLUSIVE`, `FAILED`, `ABORTED`, and approval-only states cannot create or imply a receipt.
- Evidence model: the run persists pre-action subscription truth before browser execution. A receipt binds that record to the first account screenshot, exact approval snapshot and fingerprint, crash-safe execution attempt, and strongest fresh-session verification evidence. Missing optional evidence remains explicit `null`; receipt construction does not infer or fabricate unobserved facts.
- Persistence and recovery: SQLite schema version 4 stores one immutable receipt per job, enforced by a unique job constraint and update/delete triggers. Receipt creation runs after the verification transaction. A failure cannot roll back `VERIFIED`; safe failure metadata and attempt count are persisted for an idempotent retry.
- Integrity: canonical version `1` recursively sorts object keys, preserves semantically ordered arrays, rejects undefined/non-finite values, and serializes explicit nulls. SHA-256 covers the complete logical receipt payload. The product describes this as tamper-evident and explicitly states that it is not a digital signature, identity proof, or third-party timestamp.
- Secret and path boundary: canonical receipt JSON contains guarded application evidence URLs, never local absolute paths, cookies, profile contents, API keys, or auth headers. Credential-bearing replay query strings are excluded. Replay availability remains supporting evidence and never changes verification truth.
- UI and API: `/receipts/[id]` renders the verified outcome, $359.88/year eliminated, OFF/NONE billing facts, distinct execution and verification browser IDs, before/approval/action/verification evidence, replay state, and integrity digest. `GET /api/receipts/:id` provides the safe logical JSON and download response. The dashboard and demo link to a receipt only for a verified cancellation.
