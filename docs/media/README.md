This is a **20-second edited highlight**, not the original proof recording.
It uses tightly cropped controls from the completed real Miro Business Trial
cancellation. Pacing, zooms, highlights and captions were added locally.

The final panel is an editorial summary of the verified job: one acknowledged
final click, one authorization use, zero retries and zero unsafe actions.
It is not a fabricated provider confirmation screen. Independent verification
and the private receipt—not this video—establish the outcome.

## Privacy

Only locally checked, allowlisted generic control labels and the fixed neutral
reason were copied from the recording. All other source pixels were excluded:
no browser chrome, account/company identifiers, billing background, card details,
passwords or original audio are included. The source recording and receipt remain
unchanged in ignored private storage.

The edit intentionally omits the surrounding provider screen and the full
execution/verification timeline. Its duration is not a latency benchmark.
Do not substitute a raw recording or a card-only-blurred full screen without
another privacy review.

## Formats

| Asset                 | Format                            | Purpose                          |

Both files were encoded locally using FFmpeg; metadata and audio were removed.
No video editor or extra runtime dependency was added to the application.
The public assets are versioned; private frame exports and source recordings
must remain ignored.
